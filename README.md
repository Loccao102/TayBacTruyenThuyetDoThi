# Tây Bắc — Nhật ký di sản

Prototype concept cho website khám phá di sản Tây Bắc.

## Concept

Modern Heritage Editorial — một cuốn sổ di sản tương tác:

- Opening như mở một cuốn sổ.
- Chuyển giữa các section bằng page-turn.
- Paper texture, grain và shadow.
- Parallax nhẹ theo chuột.
- Bản đồ minh họa với marker tương tác.
- Editorial layout cho ảnh và nội dung.
- Menu mục lục dạng slide-over.
- Responsive mobile và hỗ trợ giảm motion.

## Chạy

Prototype tĩnh, không cần build step. Mở index.html hoặc deploy thư mục lên Vercel, Netlify hoặc GitHub Pages.

## Ảnh prototype

Ảnh minh họa lấy từ Wikimedia Commons. Khi chuyển production nên thay bằng ảnh chính thức hoặc ảnh do dự án sở hữu và lưu metadata bản quyền trong CMS.

## Hướng phát triển

1. Tách spread thành component thật.
2. Kết nối DB di tích.
3. Map thật + filter tỉnh/loại.
4. Trang chi tiết di tích.
5. Gallery/video CMS.
6. Quiz + facts.
7. Sổ tay + badge.
8. GSAP hoặc Framer Motion cho page-turn nâng cao nếu cần.
